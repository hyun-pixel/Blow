01

이용 문의와 승인

정식 판매가 시작되면 아래 순서로 이용합니다. 현재는 테스트용 설치파일을 제공하며, 정식 판매는 준비 중입니다.

  1. 1

    먼저 이용을 문의하세요.

    Windows PC와 Chrome, 네이버 계정, 개인 OpenAI API가 준비되어 있는지 확인합니다. 가격과 이용 범위, 환불 조건도 함께 안내받으세요.

  2. 2

    설치하고 이메일을 인증하세요.

    안내받은 설치파일로 BLOW를 설치합니다. 프로그램에서 본인의 이메일로 회원가입한 뒤, 받은 인증 메일의 안내에 따라 인증을 완료하세요.

  3. 3

    결제 안내 후 이용 승인을 받으세요.

    개별 안내받은 계좌로 결제하면 운영자가 입금을 확인하고 이용권을 승인합니다. 이용 승인 완료는 운영자가 가입 이메일로 안내합니다. 설치나 회원가입만으로 이용권이 시작되지는 않습니다.

    ✓

    30일 이용권은 관리자 승인 시각부터 정확히 30일간 이용합니다.
    시작·만료 시각은 한국 시간 기준으로 승인 이메일과 프로그램에서 확인하세요.

02

블로그 세팅

프로그램의 ‘블로그 세팅’에서 브랜드 정보와 연결을 준비합니다.

  1. 4

    브랜드의 기본 정보를 저장하세요.

    브랜드명, 업종, 서비스 소개와 원하는 말투를 입력합니다. 글 끝에 들어갈 문의 문구도 함께 준비해두면 다음 글에 재사용할 수 있습니다.

    브랜드 정보
    이름 · 업종 · 상품·서비스
    글의 분위기
    원하는 말투와 표현
    마지막 안내
    소개 · 문의 · 필수 문구
  2. 5

    본인의 OpenAI API를 연결하세요.

    개인 OpenAI API 키를 등록하고 연결 상태를 확인합니다. 글과 이미지 생성에 사용하는 API 요금은 BLOW 이용료와 별도로 발생합니다. API 키와 비밀번호는 다른 사람에게 전달하지 마세요.

  3. 6

    네이버 계정과 블로그를 확인하세요.

    BLOW에서 여는 전용 Chrome에서 본인의 네이버 계정으로 로그인합니다. 실제 연결된 계정과 사용할 블로그가 맞는지 확인한 뒤 새 글 작성으로 이동하세요.

    로그인 보호 화면이 나오면 네이버가 제공하는 본인 확인 절차를 따르세요. 연결이 끊겼다면 다시 연결한 뒤 진행합니다.

03

작성부터 임시저장까지

한 편씩 쓰거나 여러 주제를 작성 목록에 준비할 수 있습니다.

  1. 7

    글마다 주제와 설정을 정하세요.

    ‘새 글 작성’에서 주제, 글 유형, 길이, 키워드와 마지막 안내 문구를 설정합니다. 이미지 사용 여부와 스타일, 인용구·스티커·구분선도 필요한 만큼 선택하세요.

    여러 편을 작성할 때는 ‘목록에 추가’로 글별 설정을 준비하고, 실행 전 목록을 확인하세요.

  2. 8

    비용 안내를 확인하고 실행하세요.

    실행 전 작성할 글과 API 비용 안내를 확인합니다. BLOW가 글과 이미지를 생성하고, 네이버 편집기에 입력한 뒤 임시저장합니다. 여러 글은 순서대로 진행합니다.

    i

    작업 중에는 PC 종료·절전과 작성 중인 브라우저 조작을 피해주세요. 저장 여부가 불확실하면 다시 실행하기 전에 네이버 임시저장 목록부터 확인하세요.

  3. 9

    저장된 글을 검토하고 직접 발행하세요.

    ‘작업 내역’에서 결과를 확인하고 네이버 임시저장 글을 열어보세요. 사실관계와 문장, 이미지와 사용 권한을 검토하고 필요한 부분을 수정한 뒤 직접 발행합니다.

    ✓

    BLOW는 임시저장까지.
    최종 발행은 직접 진행합니다.

04

계정과 이용 관리

비밀번호를 잊었다면

로그인 화면의 ‘비밀번호 찾기’를 선택합니다. 가입 이메일로 받은 인증 코드를 확인한 뒤 새 비밀번호를 두 번 입력하고 저장하세요.

이용 기간을 연장하려면

자동 결제 없이 이용 문의로 연장을 신청합니다. 만료 전에 승인되면 기존 만료 시각에 30일을 추가해 남은 기간을 유지합니다. 이미 만료됐다면 새 승인 시각부터 30일로 시작합니다.

PC나 블로그를 바꾸려면

기본 이용 범위는 계정 1개, PC 1대, 네이버 블로그 1개입니다. 등록 환경 변경이 필요하면 문의해주세요.

새 버전으로 업데이트하려면

최신 설치파일을 다시 내려받아 설치하는 방식입니다. 기존 설정 보존과 업데이트 순서는 배포 안내를 확인하세요.
