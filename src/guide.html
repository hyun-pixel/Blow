나만의 설정

i

현재 프로그램 UI를 개발하고 있습니다. 이 가이드는 이용 순서를 먼저 안내하며, 실제 화면과 버튼별 설명은 UI가 완성되면 추가됩니다.

  1. 05

    OpenAI API와 네이버를 연결하세요.

    본인의 OpenAI API를 등록하고 Chrome에서 네이버 로그인을 진행합니다. API 이용료는 OpenAI에서 별도로 발생합니다. API 키나 비밀번호를 다른 사람에게 전달하지 마세요.

  2. 06

    브랜드 정보를 설정하세요.

    브랜드명, 업종, 서비스 설명과 원하는 말투를 준비합니다. 꼭 들어가야 하는 문구나 상담 안내도 설정할 수 있습니다.

첫 번째 글 작성

  1. 07

    주제와 자료를 넣고 작성하세요.

    오늘의 주제와 키워드, 참고자료를 준비합니다. 사용할 사진과 이미지 배치, 강조·인용구 등 서식을 설정해 글을 구성하세요.

  2. 08

    임시글을 확인하고 직접 발행하세요.

    BLOW가 글과 이미지를 네이버 편집기에 입력하고 임시저장합니다. 사실관계, 사진, 표현과 서식을 확인한 뒤 직접 발행하세요.

    ✓

    BLOW의 자동화 범위는 임시저장까지입니다.
    최종 발행은 사용자가 직접 진행합니다.
