# BLOW 홈페이지

브랜드 블로그 작성 도구 BLOW의 로컬 홈페이지 시안입니다. 공식 배포·도메인 연결 전이며 모든 페이지에 검색 수집 제외 설정이 들어 있습니다.

## 현재 구성

- 메인: 중앙 히어로와 영상 준비 영역, 업종별 예시 전환, 기능 패널, 선택형 작성 과정, 요금제와 전화 상담.
- 사용 가이드: 상담 → 설치·가입 → 결제 → 관리자 승인 → 설정 → 임시저장·직접 발행.
- 다운로드: 실제 설치파일 미수령에 따른 준비 중 상태.
- 정책 3종: 기존 Markdown 초안을 자동으로 웹페이지로 변환. 확정 정책이 아닙니다.
- Cafe24Simplehae 400 웹폰트 자체 제공. 일반 방문 통계 스크립트는 아직 없음.

## 로컬 실행

Node.js와 pnpm이 설치된 환경에서 다음 순서로 실행합니다.

1. 프로젝트 폴더에서 pnpm install --frozen-lockfile
2. pnpm dev
3. 브라우저에서 http://127.0.0.1:4173 열기

본문·정책을 수정하면 pnpm build 후 브라우저를 새로고침합니다. 서버는 dist 폴더만 127.0.0.1에 제공합니다. 로컬 확인용 서버이므로 그대로 인터넷에 공개하지 않습니다.

## 확인 명령

pnpm build
pnpm check

브라우저 검수는 별도 검수 환경에서 수행하며 결과와 스크린샷은 Git에서 제외된 work 폴더에 보관합니다. 빌드·검사는 설치파일 자체나 프로그램의 실제 기능을 테스트하지 않습니다.

## 공개 전 남은 자료

카카오 채널 URL, 정식 프로그램 화면, 실제 설치파일과 버전·크기·지원 환경, 기간·환불의 상세 계산 기준, 운영자·개인정보 처리방침 정보가 필요합니다. 법정 사업자 고지와 호스팅·통계 제공업체도 공개 전 확정해야 합니다.

검색 수집 제외 설정은 초안·자료·법정 고지 확인이 끝난 정식 공개 단계에서 변경합니다. 그 전에 임의로 제거하지 않습니다. 외부 배포·DNS 변경·유료 서비스 개설은 별도 승인 대상입니다.

## 디자인 기준

사용자가 지정한 [Glaze](https://www.glaze.app/)의 구조와 컨셉을 참고해 짙은 배경, 중앙 캡슐형 고정 메뉴, 가운데 정렬한 히어로, 큰 영상 자리와 크기가 다른 기능 패널로 구성했습니다. Cafe24Simplehae와 확정된 BLOW 정보는 유지합니다.

Glaze 원본 영상은 재사용 허용을 확인하지 못해 복제하지 않았습니다. 사용자 요청에 따라 영상 영역은 “소개 영상 준비 중”으로 남겨 두었습니다. 예시는 실제 프로그램 화면이나 고객 결과가 아님을 표시합니다.

모바일에서는 메뉴가 접히고 기능 패널이 1열로 이어집니다. 짧은 등장 모션과 선택 전환을 적용했으며 동작 줄이기 설정을 지원합니다. 상세 변경 사항은 outputs/BLOW_홈페이지_디자인변경_v1.1.md에 기록했습니다.
