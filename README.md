# BLOW 홈페이지

브랜드 블로그 작성 프로그램 BLOW를 소개하는 정적 홈페이지입니다. 2026년 10월 1일 승인된 첫 화면을 바탕으로 메인·가이드·다운로드·정책 페이지의 로컬 리뉴얼을 구현했습니다.

현재 홈페이지 문구는 **이용 문의 후 개별 결제·운영자 승인을 받는 유료 서비스** 기준입니다. 2026-10-02 사용자 결정에 따라 안내 문구를 확정했습니다. 배포는 기존 Vercel 연동을 사용합니다. 기존에 승인된 0.1.11 설치파일 링크를 유지하고, 실제 판매자 정보와 시행일이 필요한 정책은 초안 상태로 구분합니다.

## 현재 작업 범위

2026-10-02 사용자 요청에 따라 홈페이지 제작·디자인을 우선합니다. 프로그램 기능 검수, 새 설치파일 테스트와 운영 서비스 설정은 별도 제품 작업이며 홈페이지 디자인 진행 조건으로 두지 않습니다. 인증메일은 사용자가 회원가입 인증과 비밀번호 재설정 모두 정상 완료했다고 확인했습니다.

## 현재 구성

- 메인: 작성 과정 애니메이션 → 핵심 기능 → 작성 흐름 → 이용 문의. 프로그램 설명과 장점에 집중합니다.
- 요금 안내: /pricing/에서 30일 이용권 가격·범위·별도 API 비용·환불 안내와 이용 문의를 제공합니다. 상단 메뉴는 별도 페이지로 연결합니다.
- 사용 가이드: 문의와 승인, 블로그 세팅, 글 작성과 임시저장, 계정·이용 관리.
- 다운로드: BLOW-Setup-0.1.11-x64.exe 정보, Windows x64 준비 사항, 설치파일 다운로드와 전자 서명 없음 안내.
- 정책 3종: 이용약관·개인정보처리방침·결제 및 환불 안내의 리뉴얼 초안. 시행 중인 정책으로 표시하지 않음.
- 밝은 흰색·초록색과 Cafe24 써라운드 v2.0 웹폰트.
- 모든 시안 페이지에 noindex,nofollow, robots.txt에 Disallow: / 적용.
- 하단에는 사업자등록번호·주소를 표시하지 않음. 시안용 가상 정보는 이용약관 초안에서만 예시로 명시.

첫 화면 제목은 다음 세 줄을 유지합니다.

> 글 작성부터\
> 이미지 생성까지\
> BLOW가 도와드립니다.

작성 과정은 실제 앱 화면이나 처리 속도가 아닌 예시입니다. 6.8초 동안 한 번 재생하며, 일시정지·계속 재생·다시 보기·동작 줄이기를 지원합니다. 최종 검토와 발행은 사용자가 직접 한다고 안내합니다.

## 로컬 실행

Node.js와 pnpm이 설치된 환경에서 프로젝트 폴더를 열고 실행합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

전체 미리보기: http://127.0.0.1:4173/

본문·정책을 변경하면 아래 명령으로 HTML을 다시 만든 뒤 브라우저를 새로고침합니다.

```sh
pnpm build
pnpm check
```

첫 화면만 확인하려면 `pnpm preview:hero`를 실행하고 http://127.0.0.1:4173/preview/hero/ 를 엽니다. 서버가 이미 실행 중이면 `node scripts/build.mjs --hero-preview`만 실행합니다.

일반 빌드는 독립 요금 안내를 포함한 리뉴얼 7개 페이지를 생성합니다. `--hero-preview`는 별도의 첫 화면 확인 경로를 추가합니다. 서버는 dist를 127.0.0.1에서 제공하는 로컬 확인용입니다.

## 홈페이지 모션 (2026-10-02)

- 후속 요청에 따라 히어로 아래 Windows·API 안내 줄과 편집기 위 예시·재생 버튼 줄을 제거했습니다. 애니메이션은 6.8초 작성 과정과 2초 완료 화면을 자동 반복하며, 보이지 않는 화면·탭에서는 정지하고 복귀 시 재개합니다. 동작 줄이기 설정과 JavaScript 미사용 환경은 완성 화면을 제공합니다.

- 기존 밝은 초록색과 Cafe24 써라운드 디자인에 커서 링, 카드 조명·기울기, 버튼의 작은 자석 반응을 추가했습니다. 마우스 포인터 자체는 에메랄드색 SVG로 교체했으며, 링크 위에서 밝은 포인터와 작은 표시로 바뀝니다. 뒤따르는 장식은 클릭을 가로채지 않습니다.
- 제목·섹션·카드의 첫 등장, 이미지 펼침, 작성 목록의 순차 등장, 단계 연결선 그리기, 메뉴 밑줄과 버튼 화살표 반응을 제공합니다.
- 화면 상단의 스크롤 진행선은 CSS scroll timeline 지원 브라우저에서 표시합니다. 지원하지 않는 브라우저는 기본 화면을 그대로 제공합니다.
- 터치 화면은 커서·기울기 없이 짧은 등장 효과를 사용합니다. 운영체제의 동작 줄이기 설정을 실시간 반영하고, 키보드로 초점을 옮긴 콘텐츠는 등장 애니메이션을 즉시 마칩니다.
- 내용은 기본적으로 표시되며 JavaScript가 꺼져도 읽을 수 있습니다. 모션은 기존 site.css·site.js에 작성했고 별도 패키지를 추가하지 않았습니다.
- 로컬 브라우저 검사: work/motion-check.mjs. 결과·캡처: work/motion/. 기존 36개 반응형 화면 검사와 타이핑·일시정지·재생 검사도 통과했습니다.
## 공개 전 남은 준비

- 정식 배포 파일 확정. 현재 0.1.11은 사용자 승인으로 테스트용 공개했고, 117,307,385바이트(약 117.3MB)이며 코드 서명이 없습니다. 공개 URL과 검증 결과는 outputs/BLOW_설치파일_공개준비_v0.1.11.md에 기록했습니다.
