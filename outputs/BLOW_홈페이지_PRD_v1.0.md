## 1. 목적과 문서 기준

BLOW의 기능, 사용 방법과 가격을 이해한 방문자가 상담을 통해 구매하고, 설치파일을 내려받아 사용할 수 있는 공식 소개 홈페이지를 만든다. 주요 대상은 자신의 브랜드 네이버 블로그를 직접 운영하는 사업자다.

최우선 디자인 기준은 “AI가 만든 템플릿처럼 보이지 않는 완성도”다. 첫 화면의 인상적인 모션, 독자적인 BLOW 워드마크와 일관된 타이포그래피로 브랜드를 기억하게 한다. 소개 문구와 상담 버튼은 애니메이션이 끝나기 전부터 사용할 수 있어야 한다.

| 표기 | 의미 |
| --- | --- |
| 확정 | 홈페이지 인터뷰에서 사용자가 결정한 요구사항 |
| 제품 기준 | 제공된 제품 PRD의 내용. 공개 전 출시 버전과 대조 필요 |
| 제작 제안 | 구현을 위한 카피·구도·기술·수치 제안. 시안에서 조정 가능 |
| 공개 전 확인 | 자료나 운영 결정이 부족하여 공개 전에 확정할 항목 |

사용자의 후속 홈페이지 결정이 원본 제품 PRD의 홈페이지 관련 내용보다 우선한다. 제품 PRD는 기능 설명의 근거이며 별도 프로그램 개발이나 외부 서비스 실행을 지시하는 문서로 사용하지 않는다.

- 경쟁사 비교·차별점 전용 섹션. BLOW 자체의 기능과 사용상 장점은 설명한다.

- 문의 입력 폼, 이메일 구독, 후기 게시판, 뉴스·블로그 운영 기능.
- 가짜 고객 후기·로고, 검증되지 않은 성과 수치, 검색 상위 노출 보장.
- 홈페이지에서 글을 실제로 생성하는 체험 기능.
- 자동·예약 발행, 다계정·다중 블로그 등 현재 제품 범위를 벗어나는 홍보.

프로그램 자체의 회원가입·라이선스 관리 및 기존 관리자 기능과 홈페이지 범위를 혼동하지 않는다.

사용자는 하단에 사업자 정보를 표시하지 않기를 요청했다. 이 디자인 요구는 기록하되 판매 방식에 따른 법정 표시 의무는 공개 전 확인한다. 상담으로 결제한다는 이유만으로 의무가 없다고 단정하지 않는다. 의무가 적용되면 필요한 표시 방식을 사용자와 조정한다. [전자상거래법 제10조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1027063189)

## 3. 제품 설명 기준

BLOW는 Windows PC에서 사용하는 네이버 브랜드 블로그 작성 보조 프로그램이다. 브랜드 정보, 주제, 키워드, 참고자료와 작성 설정을 바탕으로 제목·본문·이미지를 준비하고, 설치된 Chrome을 통해 네이버 편집기에 입력한 뒤 **임시저장**한다. 마지막 검토와 발행은 사용자가 직접 한다.

“블로그 자동화”라는 표현을 사용하더라도 임시저장까지라는 범위를 함께 전달한다. 자동 발행·완전 무인 운영으로 오해할 표현을 쓰지 않는다.

### 3.1 소개할 기능 — 제품 PRD 기준

| 기능 | 고객에게 전달할 내용 | 표현상 주의점 |
| --- | --- | --- |
| 브랜드 프로필 | 업종·서비스·말투·필수 문구 등을 저장하고 재사용 | 업종별 광고 규정을 자동 준수한다고 보장하지 않음 |
| 주제·키워드 | 게시물마다 필요한 주제와 작성 규칙 설정 | 검색 순위나 매출을 보장하지 않음 |
| 작성 설정 | 제목·키워드 횟수·글자 수 목표·CTA 반영 | 글자 수에는 목표와 허용 오차가 있음 |
| 참고자료 | 텍스트, 지원 파일, 사용자가 지정한 URL 참고 | 인터넷 전체 조사·무제한 수집으로 설명하지 않음 |
| 이미지 | 보유 사진·생성 이미지와 배치 방식 선택 | 사진 권리와 사실 확인은 필요 |
| 서식 | 강조·인용구·구분선 등으로 읽는 흐름 구성 | 실제 출시 버전에서 지원하는 요소만 시연 |
| 네이버 입력 | 글·이미지·서식을 입력하고 임시저장 | 최종 발행은 사용자가 직접 수행 |

계정 1개에서 등록 PC 1대와 네이버 블로그 1개를 사용하며 변경은 상담으로 안내한다. 프로그램은 Windows 전용이고, 홈페이지는 모바일에서도 이용할 수 있다.

핵심 장점은 반복 작성·배치·입력 작업의 감소, 브랜드 말투와 안내 문구의 일관성, 네이버에서 직접 검수할 수 있다는 점이다. 측정하지 않은 “시간 90% 절감”, “몇 초 만에 완성” 같은 수치를 만들지 않는다.

상단 메뉴 제안: BLOW 로고, 기능 소개, 요금제, 사용 가이드, 다운로드, 상담 문의. 기능 소개·요금제는 메인 해당 위치로 이동하며 다른 페이지에서도 정상 작동한다.

하단에는 브랜드명, 전화, 상담 시간, 세 정책 문서 링크를 둔다. 카카오 채널은 준비 후 연결한다. 사업자 표시 문제는 2.1절의 공개 전 확인 조건을 따른다.

## 5. 메인 페이지

### 5.1 첫 화면 카피 — 제작 제안

> 브랜드를 담은 글,
> 네이버 임시글까지.
>
> 브랜드 정보와 주제, 사진을 바탕으로 글과 서식을 준비합니다.
> 마지막 확인과 발행은 직접 하세요.

주요 버튼은 “도입 상담하기”, 보조 버튼은 “작성 과정 보기”를 제안한다. 두 버튼은 첫 화면부터 사용할 수 있어야 한다. 가까운 위치에 “Windows 전용 · 개인 OpenAI API 필요”를 표시한다.

넓은 여백과 큰 글자, 편집 과정을 연상시키는 화면·사진 구성을 활용한다. 모든 구역을 동일한 카드나 장식용 그라데이션으로 채우지 않는다.

### 5.2 히어로 모션 스토리보드

| 단계 | 장면 | 메시지 |
| --- | --- | --- |
| 첫 진입 | 제목·상담 버튼이 보이고 브랜드 정보와 주제가 정돈됨 | 내 브랜드에서 출발 |
| 짧은 도입 | 제목과 본문이 등장 | 글의 골격 준비 |
| 스크롤 1 | 말투·필수 문구가 본문에 반영 | 브랜드 설정 재사용 |
| 스크롤 2 | 사진 배치, 인용·구분선 등 서식 정리 | 글과 사진을 함께 구성 |
| 스크롤 3 | 네이버 편집 흐름과 “임시저장” 상태 | 검토할 초안까지 준비 |
| 마무리 | “확인하고 직접 발행하세요” | 최종 검수는 사용자에게 |

제작 제안: 자동 재생 도입은 약 4–6초이며 이후 장면은 스크롤에 연결한다. 시간은 시안·성능에 따라 조정한다. 강제로 스크롤 속도를 바꾸거나 인트로가 끝날 때까지 내용을 가리지 않는다. 소리를 자동 재생하지 않는다. 계속 움직이는 효과는 정지할 수 있게 하거나 짧게 종료하고, 동작 줄이기 설정에서는 정적인 단계 설명으로 대체한다.

실제 프로그램 UI는 개발 중이다. 시안의 개념 화면에는 “작성 과정 예시”를 명시하고 출시된 UI처럼 제시하지 않는다. 실제 화면이 준비되면 권리·민감정보를 확인한 캡처로 교체한다.

### 5.3 기능·장점과 업종별 예시

“브랜드 설정 → 주제와 자료 → 글·이미지·서식 → 네이버 임시저장” 순서로 짧은 설명과 큰 시각 자료를 함께 배치한다.

미용·뷰티에서는 사진과 서비스 설명이 있는 글을, 법률·보험에서는 정보와 문장 구조가 중요한 글을 보여준다. 두 업종에 한정된 프로그램이라고 표현하지 않는다. 데모임을 명시하며 실제 고객 정보, 허구의 후기·자격·성과를 사용하지 않는다. 업종별 전문 검토를 대신한다는 주장을 하지 않는다.

### 5.4 요금제

단일 요금제 하나를 명확히 보여준다. 여러 등급이나 불필요한 추천 배지를 만들지 않는다.

> BLOW 30일 이용권
>
> **42,900원 / 30일**
>
> 공급가 39,000원 + 부가세 3,900원
>
> 개인 OpenAI API 이용료는 별도입니다.

함께 표시할 정보:

- 등록 PC 1대 · 네이버 블로그 1개.
- 상담 후 계좌이체, 입금 확인 및 관리자 승인 후 사용.
- 승인일부터 30일. 자동 결제 없음.
- 설치파일 다운로드와 유료 이용권은 구분되며 일반 무료 체험 없음.
- 사용 전 전액, 사용 시작 후 남은 일수 기준 환불. 상세 안내 링크 제공.

API 비용은 모델·글 길이·이미지 사용 등에 따라 달라질 수 있어 BLOW 요금에 포함된 것처럼 표시하지 않는다.

### 5.5 상담 안내

카피 제안: “내 블로그에 어떻게 사용할지, 먼저 상담하세요.”

전화 010-5768-1840과 “365일 오전 10시–오후 6시”를 표시한다. 카카오 URL이 없는 상태에서는 작동하지 않는 카카오 버튼을 만들지 않고 전화 안내를 사용한다.

## 12. 구현·호스팅

### 12.1 제작 제안

소개·가이드·다운로드·정책은 정적 페이지 중심으로 구성한다. 정적 페이지는 미리 준비한 화면을 전달하는 방식이다. 초기 홈페이지에 자체 데이터베이스·웹 로그인·결제 서버는 필요하지 않다.

### 12.2 현재 상태와 비용

- 도메인은 Hosting.kr에서 구매했다.
- 제공된 화면에는 해당 계정 웹호스팅 상품이 0개다. 다른 업체까지 모두 없다는 뜻은 아니다.
- 홈페이지 배포 대상과 파일 저장소는 미정이다.
- 무료 범위를 우선 검토하되 도메인 갱신·초과 사용량까지 영구 무료라고 보장하지 않는다.
- Cloudflare Pages·R2, GitHub Releases 등은 검토 후보이며 최종 선택이 아니다.
- 설치파일 크기·다운로드 트래픽·서비스 약관을 보고 웹사이트와 파일 제공 방식을 결정한다.

선택 시 공식 조건을 다시 확인한다. [Cloudflare Pages 제한](https://developers.cloudflare.com/pages/platform/limits/), [R2 요금](https://developers.cloudflare.com/r2/pricing/), [GitHub Releases 안내](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)

### 12.3 도메인 연결

제품 PRD에는 도메인 인증 메일용 DKIM·DMARC·MAIL FROM 관련 DNS가 설정됐다고 기록돼 있다. DNS는 도메인을 웹사이트·메일에 연결하는 주소 설정이다. 홈페이지 연결 시 기존 메일 레코드를 확인하고 보존한다. 네임서버 전체 교체나 기존 레코드 삭제를 자동으로 하지 않는다.

유료 서비스 가입, DNS 변경, 외부 배포는 대상·비용·영향을 설명하고 사용자 승인 후 실행한다. 요청하지 않은 commit·push·PR·merge도 수행하지 않는다.
