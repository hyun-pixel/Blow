# BLOW 홈페이지 디자인 변경 v1.1

작성일: 2026-09-18
상태: 로컬 미리보기 / 외부 배포 전

## 적용 기준

사용자가 지정한 https://www.glaze.app/ 의 레이아웃과 시각적 컨셉을 참고했다.
이번 요청은 기존 PRD v1.0의 밝은 배경·배치·모션 방향을 대체한다.
PRD 인터뷰에서 확정한 기능, 가격, 이용 순서와 Cafe24Simplehae 폰트는 유지한다.
기존 1차 시안은 work/BLOW-before-glaze-redesign.zip에 백업했다.

## 화면 구성

1. 어두운 배경 위 중앙 캡슐형 고정 메뉴.
2. 중앙 정렬 제목·설명, 상담 및 가이드 버튼.
3. 큰 영상 영역. 현재 “소개 영상 준비 중”으로 표시.
4. 브랜드 설정 / 글·사진 / 직접 발행에 대한 세 가지 요약.
5. 미용·뷰티와 법률·보험의 글 구성 예시를 전환하는 탭.
6. 전체 폭 작성 흐름, 2열 기능 패널 네 개, 전체 폭 시작 순서.
7. 30일 이용권 안내와 상담 영역.
8. 간결한 하단 링크. 사용 가이드·다운로드·정책 페이지에도 같은 시각 체계 적용.

경쟁사 비교와 FAQ는 추가하지 않았다.
프로그램 UI가 아닌 구성 예시임을 표시한다.
모바일에서는 메뉴를 접고, 예시를 2열·기능 패널을 1열로 배치한다.

## 영상과 자산

Glaze 원본 영상의 재사용 허용을 확인하지 못했으므로 복제하거나 외부 링크로 삽입하지 않았다.
사용자가 허용한 빈 영상 영역으로 두었다. 재생 버튼처럼 오해할 수 있는 작동하지 않는 버튼은 없다.
추후 BLOW 소개 영상이 준비되면 같은 영역에 교체할 수 있다.
Glaze의 코드·로고·이미지·폰트는 복제하지 않았다.
기존 Cafe24 폰트와 출처가 기록된 Pexels 사진은 유지했다.
