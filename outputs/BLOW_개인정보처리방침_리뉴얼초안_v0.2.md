# BLOW 개인정보처리방침

버전 0.2 · 작성일 2026년 10월 1일 · 최종 수정일 2026년 10월 2일 · 시행일 미확정

> 검토용 초안입니다. 외부 서비스의 처리 지역, 항목별 보유 기간과 실제 개인정보처리자를 확인한 뒤 최종 공개합니다. 현재 운영 중인 정책을 대체하는 문서가 아닙니다.

## 1. 개인정보 처리 목적과 항목

다음은 현재 제품 자료, 기존 정책과 확정된 운영 인터뷰를 바탕으로 정리한 처리 범위입니다. 정식 판매 시 예정된 결제·환불 처리를 포함하며, 판매 준비 과정에서 실제 운영 설정과 대조합니다.

| 처리 목적 | 주요 항목 |
| --- | --- |
| 회원가입·로그인·계정 복구 | 이메일, 이용자 식별번호, 인증 여부, 비밀번호 인증 정보, 계정 상태 |
| 이용권과 등록 환경 관리 | 이용 시작·종료 시각, 이용 상태, 기기 구분을 위한 일방향 해시값, 등록 블로그 식별 정보, 관리자 처리 기록 |
| 인증·보안 이메일 | 수신 이메일, 발송 시각·결과, 반송·수신 거부 등 전달 기록 |
| 이용 문의 | 이용자가 제공한 이름 또는 호칭, 연락처, 문의 내용 |
| 결제·환불 처리 (정식 판매 시) | 가입 이메일, 실제 결제자 확인에 필요한 결제 내역, 환불 신청 시각과 처리 결과, 환불을 신청한 경우 은행명·계좌번호·예금주명 |
| 이용 승인·환불 완료 이메일 안내 (정식 판매 시) | 가입 이메일, 이용 시작·만료 시각 또는 환불 금액·계산 내역·입금 결과, 안내 발송 시각 |
| 홈페이지 제공·보안 | 호스팅 과정에서 생성되는 IP 주소, 접속 시각, 요청 주소와 오류 기록 등 기술 정보 |

이용 승인과 환불 완료는 운영자가 가입 이메일로 직접 안내할 예정입니다. 환불 완료 안내의 계좌번호는 일부를 가려 표시합니다. 이는 가입 인증·비밀번호 재설정 이메일과 구분되는 운영 안내입니다.

비밀번호 원문은 운영자가 확인하는 정보로 취급하지 않습니다. 홈페이지에는 별도의 문의 입력 폼, 회원가입·결제 화면이나 광고·행태 분석 도구를 추가하지 않습니다.

## 2. 프로그램과 사용자 PC의 자료

제품 자료에 따른 로컬 처리 범위는 다음과 같습니다.

- OpenAI API 키는 Windows 보안 저장소를 통해 보호하며 BLOW 계정 서버에 저장하지 않는 구조입니다.
- 브랜드 정보와 작성 설정, 글·이미지와 작업 내역은 사용자 PC에서 관리합니다.
- 네이버 로그인 세션은 BLOW 전용 Chrome 프로필에 저장합니다.
- 기존 제품 자료의 기본 보관 기준은 작업 기록 30일, 생성 이미지 7일입니다. 최종 배포 버전의 설정·삭제 동작과 다시 대조합니다.

BLOW 계정 서버에 저장하지 않는다는 설명은 OpenAI나 네이버로도 전송하지 않는다는 뜻이 아닙니다. 요청한 글·이미지를 생성하거나 네이버에 입력·저장하는 데 필요한 내용은 해당 서비스로 전달됩니다.

## 3. 외부 서비스와 정보 처리

| 서비스 | 사용 목적 |
| --- | --- |
| Supabase | 프로그램 회원가입·로그인, 계정과 이용권 관리 |
| Vercel | 홈페이지 제공과 호스팅 보안·오류 기록 |
| OpenAI | 이용자가 요청한 글·이미지 생성 |
| NAVER | 로그인과 블로그 편집기 입력·임시저장 |
| Resend | 가입 인증·비밀번호 재설정 등 계정 이메일 전달 |

운영자가 직접 보내는 이용 승인·환불 완료 안내에 사용할 이메일 서비스와 보관 설정도 실제 운영 방식에 맞춰 확인합니다.

2026년 10월 1일 운영 기록에서 기존 Amazon SES 대신 Resend로 인증 이메일 연결 설정을 저장한 사실을 확인했습니다. 2026년 10월 2일 사용자가 회원가입 인증과 비밀번호 재설정을 모두 정상 완료했다고 확인했습니다.

2026년 10월 2일 확인한 현재 계정 관리 프로젝트의 기본 데이터 저장 지역은 서울(ap-northeast-2)입니다. 이는 해당 프로젝트의 기본 저장 위치이며, 이메일·지원·기록 처리 등 모든 외부 서비스의 처리가 국내에서만 이루어진다는 의미는 아닙니다. 정식 판매에 사용할 프로젝트와도 대조합니다. [Supabase 지역 안내](https://supabase.com/docs/guides/platform/regions)

제공업체별 실제 처리 항목·보유 기간·처리 국가, 위탁과 국외 이전의 적용 여부·근거·고지 내용을 공개 전에 확정합니다. 모든 정보를 국내에서만 처리하거나 외부에 전혀 전송하지 않는다고 표시하지 않습니다.

## 4. 보유와 삭제

처리 목적 달성이나 계정 삭제 요청 이후 불필요한 정보는 삭제하는 것을 원칙으로 합니다. 법령상 보관이 필요한 거래·분쟁 기록은 해당 목적과 기간에 따라 구분해 보관합니다.

가입 정보, 이용권·기기 기록, 문의·거래 기록, 환불 계좌 정보, 이메일 전달 기록과 호스팅 로그의 실제 보유 기간 및 삭제 방법을 항목별로 확정합니다. 외부 서비스의 로그·백업 삭제 조건도 최종 안내에 반영합니다.

PC에 남는 자료와 네이버에 저장된 글은 서버 계정 삭제와 별개일 수 있습니다. 계정 삭제 요청만으로 이용자의 원본 파일이나 네이버 글을 임의 삭제하지 않습니다.
