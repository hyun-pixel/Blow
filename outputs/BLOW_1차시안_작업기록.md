## 생성한 파일

- src/home.html, src/guide.html, src/download.html: 주요 페이지 원본.
- src/layout.mjs: 공통 메뉴·하단·메타 정보.
- dist/assets/site.css, dist/assets/site.js: 디자인·반응형·동작.
- dist/assets: 웹폰트, 라이선스·사진·파비콘.
- scripts/build.mjs, scripts/serve.mjs, scripts/check.mjs: 생성·로컬 실행·검수.
- dist의 HTML 6종과 robots.txt: 로컬 제공 페이지.
- README.md, ASSET_CREDITS.md: 실행·수정 안내와 자산 출처.
- package.json, pnpm-lock.yaml: Markdown 변환 라이브러리 marked의 버전 관리.
- .openai/hosting.json: 정적 제공 폴더 정보만 있음. 외부 Site 등록·배포 없음.

## 검증 결과

- 6개 경로 × 5개 화면 폭(360·390·768·1280·1440px), 총 30조합에서 가로 넘침 없음.
- 실제 Edge 엔진에서 폰트·이미지 로딩 정상, 페이지 오류·실패 응답 없음.
- 시작 모션 완료와 단계 전환, 업종 전환, 모바일 메뉴·Escape 닫기 정상.
- 동작 줄이기 설정 적용, 키보드 본문 이동 및 초점 확인.
- 다운로드 준비 중 버튼 비활성화, 가짜 설치파일 링크 없음.
- 내부 페이지·앵커·로컬 자산 경로 검사 통과.
- 39,000원 + 부가세 3,900원 = 42,900원 및 환불 예시 계산 확인.
- 모바일 모션 장식의 가로 넘침, 본문 이동 초점, 예시 설명과 편집물의 겹침을 발견하여 수정 후 확인.
- 원본 PRD와 정책 Markdown은 이번 구현에서 수정하지 않았다.

이 검증은 홈페이지 시안에 관한 것이다. 실제 프로그램 기능, 설치파일, 통화 연결 성공, 모든 보조기술·브라우저 조합이나 현장 성능 지표까지 검증한 것은 아니다.

## 남은 항목

카카오 URL, 실제 프로그램 UI·가이드 캡처, 정식 설치파일·버전·지원 환경은 아직 받지 않았다. 승인·만료 시점과 환불 일수 계산, 운영자 정보·개인정보 설정·사업자 고지·호스팅·통계 제공업체는 공개 전 확정해야 한다. 정책은 초안으로 표시했고 검색 수집도 차단했다.

디자인과 내용은 이 시안을 보며 수정할 수 있다. 실제 파일이나 URL 없이 다운로드·카카오 연결을 작동하는 것처럼 만들지 않았다.

## Git 및 배포 상태
