- 수신 이메일 주소, 발송 시각, 발송 결과

## 4. 외부 서비스 이용과 처리 위탁

BLOW는 서비스 제공을 위해 다음 외부 서비스를 사용합니다.

| 제공자 | 이용 목적 | 관련 정보 |
| --- | --- | --- |
| Supabase | 회원가입, 로그인, 계정·베타 이용 상태 관리 | 이메일, 인증·계정 정보, 이용 상태, 기기 해시, 처리 기록 |

| Vercel | 웹사이트 호스팅과 보안·오류 로그 | 접속 로그와 기술 정보 |
| OpenAI | 이용자가 요청한 글·이미지 생성 | 이용자가 프로그램에서 전송한 요청 내용 |

Supabase와 AWS의 BLOW 주 서비스 리소스는 서울 리전을 우선 사용하도록 구성합니다. 다만 Vercel, OpenAI 등 외부 서비스는 대한민국 외 지역을 포함한 글로벌 인프라에서 정보를 처리할 수 있습니다. 각 제공자의 개인정보 보호정책과 데이터 처리 조건도 함께 적용됩니다.
