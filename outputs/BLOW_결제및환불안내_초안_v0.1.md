## 1. 이용료

| 항목 | 금액 |
| --- | ---: |
| BLOW 30일 이용권 공급가 | 39,000원 |
| 부가가치세 | 3,900원 |
| 실제 입금할 합계 | **42,900원** |
| 개인 OpenAI API 이용료 | **별도** |

이용권은 계정 1개, 등록 PC 1대, 네이버 블로그 1개를 기준으로 한다. PC나 블로그 변경이 필요한 경우 상담으로 요청한다.

BLOW 이용료에는 OpenAI API 비용이 포함되지 않는다. 이용자는 본인의 OpenAI 계정·API를 준비하며, 생성 사용량에 따른 비용은 해당 사업자의 조건에 따라 별도로 부담한다. 무료 체험이나 API 무료 제공을 약속하지 않는다.

## 2. 결제와 시작 순서

1. 전화 또는 준비된 카카오 채널로 이용 상담을 한다.
2. 지원 환경과 가격·별도 비용·환불 조건을 확인한다.
3. BLOW 설치파일을 내려받고 회원가입·이메일 인증을 진행한다.
4. 상담에서 개별 안내받은 계좌로 42,900원을 입금한다.
5. 운영자가 입금과 사용할 계정을 확인한 뒤 이용권을 승인한다.
6. 승인 후 개인 OpenAI API, 네이버 로그인과 브랜드 정보를 설정하여 사용한다.

계좌번호는 홈페이지에 공개하지 않고 상담 시 개별 안내한다. 홈페이지 자동 결제나 정기 자동 출금은 제공하지 않는다.

설치파일 다운로드는 공개되어 있지만 다운로드·설치·가입만으로 유료 사용 권한이 생기지 않는다. 일반 공개 무료 체험판은 없다.

## 3. 승인과 이용기간

- 상담·승인 운영시간: **365일 오전 10시–오후 6시**, 한국 시간. 주말·공휴일 포함.
- 승인 방식: 운영시간 내 입금 확인 후 관리자가 즉시 승인하는 수동 방식.
- 이용기간: **관리자 승인일부터 30일**.
- 승인 전 대기기간을 임의로 사용기간에서 차감하지 않는다.
- 기간 연장은 상담으로 안내하며 자동 결제되지 않는다.

> 공개 전 확정: 한국 날짜 기준의 승인 당일·만료 당일 포함 방식, 정확한 만료 시각, 연장 결제 시 새 기간의 시작 기준. 실제 프로그램 표시와 승인 안내가 일치해야 한다. 아직 정해지지 않은 구체적 날짜·시간 예시는 넣지 않는다.

## 4. 기본 환불 정책

법정 청약철회나 서비스 하자·미제공 등의 별도 사유가 없는 일반적인 중도 해지에 관한 기본 정책은 다음과 같다.

| 상태 | 기본 환불 |
| --- | --- |
| 사용 시작 전 | BLOW에 납부한 이용료 전액 |
| 사용 시작 후 | 남은 이용 일수에 해당하는 금액 |
| 별도 위약금 | 없음 |

승인일부터 이용기간이 시작된다는 원칙과 “사용 시작”의 판단 기준을 실제 운영에서 일치시킨다. 단순 다운로드·가입을 사용 시작으로 보아 비용을 차감하지 않는다.

### 4.1 일할 계산

- 기준 결제금액: 부가세 포함 **42,900원**.
- 기준 기간: **30일**.
- 1일 금액: **42,900원 ÷ 30일 = 1,430원**.
- 기본 환불액: **1,430원 × 남은 일수**.

| 계산 예시 | 사용 일수 | 남은 일수 | 환불액 |
| --- | ---: | ---: | ---: |
| 사용 시작 전 | 0일 | 30일 | 42,900원 |
| 10일 사용으로 확정된 경우 | 10일 | 20일 | 28,600원 |
| 20일 사용으로 확정된 경우 | 20일 | 10일 | 14,300원 |

위 표는 계산 예시다. 특정 날짜에 요청했을 때 사용 일수가 어떻게 확정되는지는 아래 미정 항목을 해결해야 알 수 있다.

### 4.2 아직 결정하지 않은 계산 기준

- 승인 당일의 일부 시간도 1일로 계산하는지.
- 환불 요청 당일을 사용 일수에 포함하는지.
- 하루를 한국 시간의 날짜로 구분하는지, 승인 시각부터 24시간 단위로 구분하는지.
- 운영시간 밖에 접수한 요청의 기준 시각과 접수 방법.
- 환불 요청 후 사용 권한을 종료하는 시점과 추가 사용에 관한 처리.

이 사항은 인터뷰에서 확정되지 않았다. 운영자에게 유리한 방식으로 임의 결정하여 공개하지 않는다. 환불 계산 기준을 알리지 않은 채 승인일의 일부 시간이나 처리 지연 기간을 자동 공제하지 않는다.

## 5. 법정 청약철회 및 서비스 문제

적용 법령이 보장하는 권리는 위 일할 환불 정책과 별도로 보장한다.

전자상거래법이 적용되는 소비자 거래에서는 원칙적으로 법이 정한 기산점부터 7일 이내의 청약철회 규정이 적용될 수 있다. 디지털콘텐츠·서비스의 제공 개시에 따른 예외는 법정 요건과 사전 조치 충족 여부, 미제공 부분 등을 함께 판단해야 한다. 관리자 승인이나 프로그램 실행만으로 모든 청약철회권이 사라진다고 안내하지 않는다. [전자상거래법 제17조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1022341869)

표시·광고 또는 계약 내용과 다르게 제공된 경우, 하자가 있는 경우, 운영자의 사유로 이용이 불가능한 경우에는 관련 법령과 계약에 따른 환불·손해배상 등의 권리를 검토한다. 일반 중도 해지 계산만 기계적으로 적용하지 않는다.

고객의 사업자 여부만으로 모든 소비자 보호 규정이 제외된다고 단정하지 않는다. 실제 거래 목적·상대방·판매 방식에 맞게 적용 범위를 확인한다.

## 6. 환불 접수와 처리

### 6.1 접수

- 전화: **010-5768-1840**
- 상담 시간: **365일 오전 10시–오후 6시**, 한국 시간
- 카카오 채널: [실제 URL 준비 후 기재]
- 운영시간 외 요청을 남길 수 있는 수단: [실제 접수 방식 확정]

환불 요청 시 필요한 정보는 가입 이메일 등 계정 확인 정보, 입금자명·입금일·금액과 환급에 필요한 계좌 정보로 최소화한다. 비밀번호·전체 API 키·불필요한 신분증 사본을 요구하지 않는다.

### 6.2 처리 순서 — 운영 제안

1. 요청 접수 시점을 기록하고 접수 사실을 안내한다.
2. 입금 내역, 계정, 승인·만료 상태와 환불 사유를 확인한다.
3. 적용되는 법정 권리를 먼저 검토하고, 일반 중도 해지는 확정된 일수 기준으로 계산한다.
4. 계산 내역과 환급액을 이용자에게 안내한다.
5. 필요한 계좌 확인 후 환급하고 이용권 처리 결과를 안내한다.
6. 관련 거래·분쟁 기록은 법정 보존 범위에 따라 관리한다.

타인 계좌로 환급을 요청하거나 입금자와 신청자가 다르면 정당한 권한을 확인할 수 있다. 확인은 필요한 최소 범위로 하고 부당한 지연 사유로 사용하지 않는다.

### 6.3 환급 기한

법정 청약철회가 적용되는 경우 디지털콘텐츠·용역의 환급 기한은 원칙적으로 청약철회한 날부터 3영업일 이내라는 법정 기준에 따른다. 운영자 확인 완료일을 새로운 기산점으로 삼아 임의로 늦추지 않는다. 지연 시 적용되는 법정 책임도 배제하지 않는다. [전자상거래법 제18조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1022341869)

일반 중도 해지의 자체 처리 목표는 **접수일부터 3영업일 이내 환급**을 제안한다. 이 자체 목표는 아직 운영자가 확정한 약속이 아니므로 확정 후 공개 문구에 반영한다. 별도로 적용되는 법정 기한보다 늦게 처리할 수 있다는 뜻은 아니다.

고객 상담은 365일 운영하지만 은행의 처리와 법정 영업일 계산은 구분한다.

## 7. 별도 비용과 예외 상황

- OpenAI에 직접 지급한 API 비용은 BLOW가 받은 금액이 아니므로 해당 사업자의 계약과 환불 절차에 따른다.
- 위 설명은 BLOW 귀책으로 발생한 손해에 대한 법률상 권리까지 제한하는 것이 아니다.
- 운영자의 승인 지연·서비스 미제공·기능 하자와 이용자의 단순 변심은 구분해서 처리한다.
- 잘못된 금액 입금, 중복 입금과 입금 계정 착오는 사실관계를 확인하여 정정·환급한다.
- 계정 탈퇴는 환불 요청의 전제조건이 아니다. 탈퇴 후에도 적법한 환불·권리 행사에 필요한 접수 경로를 제공한다.
- 환불을 이유로 이용자가 직접 보유한 원본 파일이나 네이버 게시물을 임의 삭제하지 않는다.

## 8. 변경과 안내

가격과 환불 조건을 변경하는 경우 적용일과 내용을 안내한다. 이미 성립한 계약에 불리한 조건을 법적 근거나 필요한 동의 없이 소급 적용하지 않는다.
