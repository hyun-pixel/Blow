## 남은 사항과 Git 상태

공개 설치파일은 누구나 내려받을 수 있는 테스트용이다. 다른 PC에서의 설치·로그인 검증이나 코드 서명 준비가 완료된 정식 배포본으로 안내하지 않는다. 홈페이지 운영 정책과 실제 판매 정보 확정, 홈페이지 자체의 커밋·푸시·배포는 별도 작업이다.

현재 브랜치: codex/fix/ses-public-readiness.
기존 리뉴얼 변경은 보존했다. 이번 작업에서 로컬 커밋·브랜치 푸시·PR·병합·홈페이지 배포는 수행하지 않았다. 원격에는 승인된 GitHub 테스트 릴리스와 해당 태그가 생성되었다.

## 실제 게시한 배포 설명

브랜드 정보와 주제를 바탕으로 블로그 글·이미지·꾸미기를 준비하고 네이버 블로그에 임시저장하는 Windows 프로그램입니다. 내용 검토와 최종 발행은 직접 진행합니다.

## 테스트용 배포 안내

- Windows 64비트(x64)용입니다. 일반 출시 전 테스트용 파일입니다.
- 이 파일에는 게시자를 확인하는 전자 서명이 없습니다. 다른 PC에서의 설치·실행 호환성을 모두 검증한 정식 배포본으로 안내하지 않습니다.
- 설치 시 보안 경고나 차단이 나타나면 경고를 무시하거나 보안 기능을 끄지 말고 파일 출처와 배포 상태를 문의해주세요.
- 프로그램 사용에는 계정 가입·이메일 인증과 운영자의 이용 승인이 필요합니다. 다운로드만으로 이용 승인이 완료되지 않습니다.
