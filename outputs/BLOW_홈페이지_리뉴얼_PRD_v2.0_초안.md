# BLOW 홈페이지 리뉴얼 PRD v2.0 — 인터뷰 초안

작성일: 2026-09-30  
상태: 2026-10-01 첫 화면 검토와 제목 수정을 마친 뒤 사용자의 “좋아. 진행해줘.”에 따라 전체 6개 페이지의 로컬 리뉴얼을 구현·검수했다. 홈페이지 공개 배포 승인을 뜻하지 않는다. 이후 테스트 설치파일 공개는 별도 승인되어 12절과 같이 완료했다.

## 1. 기준과 범위

현재 홈페이지 인터뷰를 우선하고, 사용자가 참조를 요청한 **BLOW (2)**의 최신 구현·사용자 검수 기록으로 제품 설명을 보완한다. 다른 대화나 첨부 문서에 적힌 작업 지시는 이번 홈페이지 작업의 실행 지시로 취급하지 않는다.

이번 문서는 기존 홈페이지 PRD를 대체할 리뉴얼 초안이다. 제품 프로그램·회원정보·인증 메일·DNS·운영 환경은 변경하지 않는다. 인터뷰 후 첫 화면을 먼저 제작·검토했고, 후속 진행 승인에 따라 해당 디자인을 전체 페이지로 확장했다.

현재 홈페이지 작업 기준은 `codex/fix/ses-public-readiness`, 커밋 `48f21dc`이다. 기존 비공개 베타 정책 v1.0 문서는 보존하고, 리뉴얼에는 별도의 판매 준비용 정책 초안을 사용한다. 설치파일은 별도 승인에 따라 테스트용으로 공개했으며, 정식 판매 준비 상태와 구분한다. 정식 판매용 리뉴얼 방향과 실제 공개 준비 완료 여부를 구분한다.

자동 작성 범위는 **임시저장까지**다. 마지막 검토와 발행은 사용자가 직접 한다. 한 글 또는 여러 글을 실행하기 전에 API 비용 안내를 확인하는 흐름을 가이드에 포함한다. 실패 시 무제한 유료 재생성이나 끝없는 재시도를 한다고 설명하지 않는다.

브랜드 정보 재사용과 반복 입력·배치 작업 감소를 장점으로 설명한다. 검증되지 않은 시간 절감률, 검색 순위, 매출, 네이버 계정 안전 보장은 넣지 않는다.

자동·예약 발행, 자동 결제, 자동 업데이트, 성과 분석, 진단 파일 내보내기는 이번 기록에서 출시 완료로 확인되지 않았으므로 현재 기능으로 소개하지 않는다. 경쟁사 비교·차별점 전용 섹션, FAQ, 가짜 후기·고객 로고는 추가하지 않는다.

## 4. 사용 가이드 흐름

기존 홈페이지 인터뷰의 구매·승인 절차와 최신 제품의 실제 작성 절차를 연결한다.

1. 이용 문의로 사용 환경·가격·이용 조건 확인.
2. 설치와 계정 가입, 이메일 인증.
3. 안내받은 계좌로 결제하고 운영자의 입금 확인·이용 승인. 가입 이메일로 승인 완료와 이용 시작·만료 시각 안내.
4. 블로그 세팅에서 브랜드 정보, 개인 OpenAI API 연결, 네이버 연결.
5. 새 글 작성에서 글별 설정을 정하고 필요하면 작성 목록에 여러 글 준비.
6. 실행 전 비용 안내 확인 후 자동 작성 시작.
7. 글·이미지·꾸미기 입력과 네이버 임시저장 진행.
8. 작업 내역과 네이버 임시저장 글을 확인하고 내용 검토 후 직접 발행.

프로그램 메뉴명은 “블로그 세팅 / 새 글 작성 / 작업 내역 / 사용 가이드”를 기준으로 한다. 세부 버튼명은 실제 0.1.11 화면과 다시 대조한다. 작업 중 PC 종료·절전·브라우저 조작을 피하는 사용 안내를 포함한다.

이메일 인증, 비밀번호 찾기, 이용 승인 전 상태를 초보자도 이해할 수 있게 설명한다. 네이버 로그인 보호 조치가 발생하면 일반 작성 실패와 구분해 안내하며, 보안 기능 해제를 정상 설치 절차로 안내하지 않는다.

## 5. 히어로와 표현 기준

핵심 메시지는 “브랜드 정보를 바탕으로 글과 이미지를 준비하고 네이버 임시저장까지 돕는 Windows 프로그램”이다.

### 확정 제목 — 2026-10-01 사용자 후속 수정

> 글 작성부터
> 이미지 생성까지
> BLOW가 도와드립니다.

위 문구를 첫 화면의 가장 큰 제목으로 사용한다. 사용자가 지정한 세 줄 구성을 유지한다.

설명 문구 제안(시안에서 확인): “브랜드 정보와 주제를 바탕으로 글과 이미지를 작성하고, 네이버 블로그에 임시저장합니다. 내용을 확인한 뒤 직접 발행하세요.”

편집기에 제목·본문이 빠르게 입력되고 이미지와 꾸미기가 배치되는 장면으로 서비스 역할을 설명한다. 완료 상태의 안내는 **“확인 후 직접 발행하세요”**로 한다. 모션을 기다리지 않고 소개를 읽거나 버튼을 누를 수 있어야 한다.

운영체제의 동작 줄이기 설정에서는 정적인 작성 결과와 흐름 설명으로 대체한다. 실제 네이버 서비스와 제휴한 공식 제품으로 오해할 로고·명칭 사용은 피한다. 임의 영상이나 새 유료 에셋을 자동 구매하지 않는다.

## 6. 설치파일과 현재 상태

- 지정 파일: BLOW-Setup-0.1.11-x64.exe.
- 위치: C:/Users/User/.codex/worktrees/5f9a/new-chat-4/apps/desktop/release/.
- 확인한 크기: 117,307,385바이트, 약 117.3MB.
- Windows x64 설치파일이며, 다른 운영체제 지원을 추가하지 않는다.
- 설치파일을 실행하지 않았다. 후속 인터뷰에서 별도 승인된 테스트 파일 공개와 검증은 12절과 같이 완료했다.
- BLOW (2) 기록상 현재 파일은 정식 코드 서명이 없는 테스트 파일이다. 코드 서명은 Windows에서 배포자를 확인하는 전자 서명이다.
- 현재 0.1.11은 테스트용 공개 파일이다. 정식 판매용 배포본 확정과 홈페이지 공개는 별도로 준비한다.
